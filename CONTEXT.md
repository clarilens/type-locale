# Locale identifiers

Shared vocabulary for country, language, currency, and web domain identifiers used across projects.

## Language

**Country**:
A geographic or political entity identified by a country code. Armenia is identified as `AM`; `hy` is not its country code.

**Language**:
A human language identified independently of any country. Armenian is identified as `hy`.

**Currency**:
A monetary unit identified independently of a country.

**Web domain zone**:
A top-level domain identifier used in web addresses. A domain zone is distinct from a country and a language.

**Source code synonym**:
An alternative code encountered in external site data that must be interpreted in the context of the field where it appears. The same spelling can identify different concepts in different contexts.

The `hy` value in a site's language field identifies Armenian directly; it is not a synonym.

**Site language**:
The language assigned to site content or interface, independent of the site's country and domain zone.
